## Provenance cautions

- “Candidate” counts are not interchangeable across runs. Lua counts distinct sized symbols; the recovered QuickJS note establishes 1,420 inventoried function records but not the exact identity scheme; CPython counts unique symbol-bounded entry addresses after alias/exclusion handling.
- A run outcome is per the recorded function unit and first failing stage. A structural artifact check does not establish whole-runtime semantic completeness.
- The GUI rollout JSONL files and persistent MBP workspaces are the primary session/artifact sources. The CPython Obsidian note and collection script are secondary durable documentation; the run workspace remains an explicit recovery TODO.
- The three interpreter-specific parser census files previously staged under this proposal were unrelated FCA/parser material; they have been removed and are not evidence for this design.
