# Generated native differential testing (draft)

Status: design only. Generated-program execution, admission, extraction, and
native comparison are not implemented or validated by this note.

The intended extension generates bounded straight-line instruction sequences
from explicitly admitted instruction forms and compares fresh WRUH-extracted
models with native execution. The generator should usually select instructions
that read locations written earlier in the block, while retaining other cases.
The bias is a generator parameter, not a coverage claim.

When an instruction form is first encountered, enqueue fresh WRUH extraction to
obtain dependency hints for subsequent generation and cache the result with its
provenance. The generator does not depend on old IXYK models. A hint must not
be treated as an independent correctness oracle or as a safety admission.

Before generated native execution is enabled, define and validate an admission
policy binding generated bytes to permitted instructions and bounded resources,
with a fail-closed sandbox. Preserve reproducible inputs and program artifacts,
and report unsupported, failed, or incomplete work separately from matches.
