# MOV instruction observer proof experiment

This experiment proves a GPR observation protocol relative to freshly extracted
Wruh/AYXG instruction models. Both machine-code fragments contain sixteen MOV
instructions (112 bytes): the input loader reads sixteen private slots; the
observer writes all sixteen GPRs to a 128-byte record without borrowing a GPR
or using the target stack.

Start with `Protocol.lean`, particularly `protocol_sound` and
`protocol_complete`. `Proof.lean` establishes the capture contract and memory
frame; `ByteCodec.lean` proves byte decoding; `Pipeline.lean` assembles the
input/output lemmas. The latter is generated by `emit_pipeline.py`.

The protocol retains the target model's complete edge and control outcome and
saves its PC before redirecting to capture. The captured register profile is
the sixteen GPRs. Flags/vector recording and a concrete Linux/Lean FFI handoff
are still open implementation/proof obligations. The modeled memory is total;
native mapping, permission, stop classification, and observer-fault behavior
are not established by these Lean theorems. `native_probe.py` is an external
calibration supervisor, not the intended final supervisor.

## Recheck the proof

Use a writable AYXG checkout and the pinned Wruh Nix environment. The adjacent
`../ayxg-mov-observer` workspace is the default; `AYXG_WORKSPACE` overrides it.
From the Wruh repository root on the Linux build host:

```sh
AYXG_WORKSPACE=/path/to/ayxg \
  nix develop --command bash experiments/mov_observer/check_pipeline.sh
```

For a fresh dependency directory, run `cache_dependencies.sh` in place of
`check_pipeline.sh` first. It fetches Mathlib's matching cache for the required
imports and then checks the proof. It does not update dependency revisions.
The checked declarations use only `propext`, `Classical.choice`, and
`Quot.sound`; there are no admitted lemmas or extra axioms.

## Regenerate and calibrate

On x86-64 Linux, inside a bounded fleet build cgroup:

```sh
nix-shell experiments/mov_observer/shell.nix \
  --run 'bash experiments/mov_observer/run_native.sh'
```

This uses the repository's locked Nix inputs and adds Hypothesis to the same
Angr interpreter. The command freshly extracts both stubs, requires exact
agreement with the committed models/bytes, and runs the capture calibration
inside bubblewrap. It leaves generated ELF files, build products and the
Hypothesis database in ignored `out/`. Never execute the generated ELF directly:
it intentionally has no exit path and requires its ptrace supervisor.

The native calibration checks 200 generated GPR/flag/XMM states, all sixteen
stores, preservation of the other sampled state, the memory frame, agreement
with the extracted model, and rejection of corrupted observations. It tests
the capture fragment, not the input loader plus a target instruction. Reserved
FP-save padding and MXCSR_MASK capability metadata are distinct from mutable
architectural register state; the original raw records are retained.
